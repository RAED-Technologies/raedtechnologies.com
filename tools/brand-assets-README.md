## Variants

- **logo-horizontal** — mark + "RAED Technologies" side by side (primary logo)
- **logo-stacked** — mark above the name
- **wordmark** — name only, no mark
- **mark** — the "R" tile on its own (`primary` = dark tile, `inverse` = white tile, `mono` = one color)
- **glyph** — the "R" + dot without the tile (transparent background)
- `dark-text` versions are for light backgrounds; `white-text` versions are for dark backgrounds.

PNG logos come in 600, 1200 and 2400 px widths; marks in 64–1024 px. All have transparent backgrounds except social images.

## Typography

**Geist** (free, Google Fonts) — Bold for "RAED", Medium for "Technologies" and headings. **Geist Mono** for small technical labels.

## Usage rules

- Keep clear space around the logo at least the width of the blue dot ×3 on every side.
- Minimum size: horizontal logo 120 px wide on screen; mark 24 px.
- Don't change colors, add shadows/outlines, or place the dark logo on dark backgrounds (use `white-text` / `inverse` instead).
